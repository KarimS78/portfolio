# Portfolio — Karim

Personal portfolio of **Karim — Product Engineer · Full-Stack Developer**.
From the lab floor to production code.

🔗 **Live site:** https://karimportfolio1.netlify.app

## About

A single-page portfolio built with plain HTML, CSS and vanilla JavaScript — no
framework, no build step. It ships in two themes:

- **`index.html`** — the main "code editor" experience.
- **`arcade.html`** — a retro-gaming variant (`KARIM.EXE`).

## Tech

- HTML5 / CSS3 (custom properties, responsive layout)
- Vanilla JavaScript
- Google Fonts (Space Grotesk, Hanken Grotesk, Space Mono)
- Deployed on Netlify

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
